# 微信塔罗 H5

基于 `Vue 3 + Vite + ant-design-vue + pnpm` 的移动端塔罗牌项目，适合部署为静态网页后，通过微信发送链接给对方直接使用。

## 启动

```bash
pnpm install
pnpm dev
```

## 打包

```bash
pnpm build
```

打包产物位于 `dist/`。由于 `vite.config.ts` 已设置 `base: './'`，可以直接部署到静态托管环境。

## 微信内直接使用的正确方式

微信不能像浏览器那样直接运行你发过去的本地 `html/js/css` 文件。实际可用方案是：

1. 本地执行 `pnpm build`
2. 把 `dist/` 部署到任意支持 HTTPS 的静态站点
3. 将访问链接发到微信，对方点开即可使用

可选部署平台：

- Vercel
- Netlify
- Cloudflare Pages
- 腾讯云静态网站托管
- 阿里云 OSS 静态网站托管
